# المنظومة الأكاديمية لاختيار وتقويم المتعلمين | بوابة المدرس

منظومة إلكترونية مهنية مخصصة للأطر التربوية والتعليمية لإدارة لوائح الفصول الدراسية، استيراد بيانات التلاميذ من ملفات Excel، وإجراء السحب العادل والمحايد للمشاركة والتقويم الصفي اليومي وفق المعايير البيداغوجية المعتمدة.

---

## الضوابط والمميزات الأساسية

1. **واجهة استخدام أكاديمية موجهة (RTL)**:
   - تصميم مؤسسي رصين مبني بالكامل لدعم اللغة العربية بتوجيه من اليمين لليسار (`dir="rtl"`).
   - خط **Cairo** عالي المقروئية على أجهزة العرض والمسلاط داخل قاعات الدرس (Classroom Projector Mode).
   - خالية من الرموز التعبيرية والأيقونات لضمان الوقار والجدية المهنية.

2. **معالجة واستيراد لوائح Excel (.xlsx / .xls)**:
   - تعرف آلي دقيق على عمود أسماء التلاميذ بمختلف الصيغ المعتمدة.
   - كشف التكرارات ومعاينة البيانات وتنقيتها قبل الإدراج في قاعدة البيانات.
   - دعم كامل للملفات متعددة أوراق العمل.

3. **آلية السحب والتقويم الصفي المحايد**:
   - خوارزمية سحب عشوائي غير منحازة تُنفذ من جهة الخادم لضمان تكافؤ الفرص التام بين جميع المتعلمين.
   - منع التكرار التلقائي: استبعاد التلميذ المختار تلقائياً من صندوق السحب حتى استيفاء جميع متعلمي الفوج.
   - شاشات عرض واضحة تبرز اسم المتعلم المختار بوضوح للقسم بأكمله.

4. **التوثيق وسجل الجولات**:
   - أرشفة تفصيلية لجميع الجولات وترتيب اختيار كل متعلم بالوقت والتاريخ للشفافية والمتابعة البيداغوجية.

5. **عزل وأمان تام لحسابات الأساتذة**:
   - نظام مصادقة مستقل لكل أستاذ مع تشفير كامل لكلمات المرور.
   - لا يمكن لأي مستخدم الاطلاع على بيانات فصول أو تلاميذ مستخدم آخر.

---

## التقنيات المعتمدة

- **الواجهة الأمامية**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Framer Motion.
- **الواجهة الخلفية**: Next.js Server Route Handlers, Zod Validation.
- **قاعدة البيانات**: SQLite (`file:./dev.db`), Prisma ORM.
- **معالجة البيانات**: SheetJS (`xlsx`).
- **الأمان والمصادقة**: Bcryptjs (Password Hashing), Jose (JWT Sessions & Secure Cookies).

---

## التشغيل المحلي

1. تثبيت الحزم:
```bash
npm install
```

2. مزامنة قاعدة البيانات:
```bash
npx prisma db push
```

3. تشغيل خادم المنظومة:
```bash
npm run dev
```
افتح المتصفح على الرابط: http://localhost:3000
